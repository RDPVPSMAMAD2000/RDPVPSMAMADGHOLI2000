# فروشگاه امیر — نسخه PHP + MySQL (آماده برای InfinityFree)

این نسخه به‌طور کامل بازنویسی شده تا روی هاست رایگان [InfinityFree](https://www.infinityfree.com/) با یک دیتابیس واقعی MySQL کار کند — دیگر به `localStorage` مرورگر یا دانلود دستی فایل JSON نیازی نیست. تمام اطلاعات محصولات در دیتابیس ذخیره می‌شود و تغییرات پنل مدیریت بلافاصله روی سایت اصلی هم دیده می‌شود.

## ساختار پروژه
```
htdocs/                  ← فقط محتوای این پوشه را در InfinityFree آپلود کن
  index.php              صفحه اصلی فروشگاه (خواندن محصولات از دیتابیس)
  robots.txt, sitemap.xml
  .htaccess              تنظیمات امنیتی پایه
  css/style.css
  js/store.js            فقط فیلتر دسته‌بندی سمت مرورگر
  includes/
    config.php           اطلاعات اتصال به دیتابیس (باید پر کنی)
    db.php               اتصال PDO به MySQL
    functions.php        توابع کمکی مشترک
    auth.php             محافظ صفحات مدیریت (بررسی ورود ادمین)
    .htaccess            جلوگیری از دسترسی مستقیم مرورگر به این پوشه
  admin/
    login.php            صفحه ورود مدیر
    dashboard.php         افزودن / ویرایش / حذف محصولات
    export.php            دانلود نسخه پشتیبان JSON از محصولات
    logout.php

database/
  schema.sql              اسکریپت ساخت جدول‌ها + کاربر مدیر پیش‌فرض + چند محصول نمونه
                          (این فایل را در htdocs آپلود نکن — فقط برای ایمپورت در phpMyAdmin است)
```

## مراحل دیپلوی روی InfinityFree

### ۱. ساخت هاست و دیتابیس
1. وارد پنل InfinityFree شو و یک هاستینگ جدید بساز (رایگان).
2. از داشبورد هاست، به بخش **MySQL Databases** برو و یک دیتابیس جدید بساز.
3. InfinityFree این ۴ مقدار را به تو می‌دهد: نام هاست دیتابیس (مثل `sql200.infinityfree.com`)، نام دیتابیس، نام کاربری و رمز عبور دیتابیس. اینها را جایی یادداشت کن.

### ۲. ایمپورت جدول‌ها
1. از همان پنل، وارد **phpMyAdmin** شو.
2. دیتابیسی که ساختی را انتخاب کن و به تب **Import** برو.
3. فایل `database/schema.sql` را انتخاب و ایمپورت کن.
4. بعد از ایمپورت باید دو جدول `admin_users` و `products` را ببینی — همراه با یک کاربر مدیر و ۳ محصول نمونه.

### ۳. تنظیم اطلاعات اتصال
فایل `htdocs/includes/config.php` را باز کن و این ۴ مقدار را با اطلاعات مرحله ۱ جایگزین کن:
```php
define('DB_HOST', 'sql200.infinityfree.com');
define('DB_NAME', 'if0_12345678_amirshop');
define('DB_USER', 'if0_12345678');
define('DB_PASS', 'رمز-دیتابیس-تو');
```
همچنین `SITE_URL` را بعد از گرفتن آدرس نهایی سایت (مرحله ۵) به‌روزرسانی کن.

### ۴. آپلود فایل‌ها
با FTP (اطلاعات آن هم در پنل InfinityFree هست، مثلاً با FileZilla) وارد هاست شو و **فقط محتوای پوشه `htdocs/`** را داخل پوشه `htdocs` هاست آپلود کن (نه خود پوشه `htdocs`، بلکه فایل‌های داخلش).

### ۵. تست سایت
بعد از چند دقیقه سایت روی آدرسی شبیه `https://youraccount.infinityfreeapp.com` بالا می‌آید (یا دامنه‌ی اختصاصی‌ای که وصل کرده‌ای). آدرس نهایی را در `SITE_URL` داخل `config.php`، و در `robots.txt` و `sitemap.xml` جایگزین کن.

## ورود مدیر
- آدرس: `/admin/login.php`
- نام کاربری: `Amir`
- رمز عبور: `admin`

**توصیه جدی:** بلافاصله بعد از اولین ورود، رمز عبور را عوض کن. ساده‌ترین راه: یک هش bcrypt جدید بساز و در جدول `admin_users` جایگزین کن. اگر به phpMyAdmin دسترسی داری، می‌توانی این کوئری را (بعد از تغییر مقدار رمز) اجرا کنی — چون تولید هش نیاز به اجرای کد PHP دارد، از من بخواه یک هش تازه برایت بسازم و همینجا در اختیارت بگذارم.

## چرا این نسخه امن‌تر و حرفه‌ای‌تر است
- **رمز عبور مدیر داخل کد نیست.** به‌صورت هش bcrypt (یک‌طرفه و غیرقابل بازگشت) در دیتابیس ذخیره شده؛ حتی با دیدن کدهای سایت، رمز واقعی قابل استخراج نیست.
- **جلوگیری از SQL Injection:** همه‌ی کوئری‌ها با Prepared Statements (PDO) نوشته شده‌اند.
- **جلوگیری از XSS:** هر مقداری که از دیتابیس یا کاربر می‌آید قبل از نمایش escape می‌شود.
- **محافظت CSRF:** فرم‌های افزودن/ویرایش/حذف و ورود، توکن یکبارمصرف دارند.
- **نشست امن مدیر:** بعد از ورود موفق، شناسه نشست دوباره تولید می‌شود (جلوگیری از Session Fixation).
- **دیتابیس واقعی:** برخلاف نسخه گیت‌هاب قبلی، دیگر نیازی به دانلود/آپلود دستی فایل JSON برای انتشار تغییرات نیست — همه‌چیز آنی و متمرکز است.
- فایل‌های تنظیمات (`includes/`) با `.htaccess` از دسترسی مستقیم مرورگر مسدود شده‌اند.

## پشتیبان‌گیری
از پنل مدیریت، دکمه «دانلود پشتیبان JSON» یک نسخه از وضعیت فعلی محصولات را دانلود می‌کند — صرفاً برای اطمینان خاطر، نه برای ذخیره‌سازی اصلی.

## محدودیت‌های شناخته‌شده InfinityFree (برای اطلاع)
- سرعت پاسخ‌دهی هاست رایگان گاهی پایین‌تر از هاست‌های پولی است.
- برخی افزونه‌های PHP ممکن است محدود باشند؛ این پروژه عمداً بدون وابستگی به افزونه‌های غیرپیش‌فرض (مثل mbstring) نوشته شده تا مشکلی پیش نیاید.
- برای ترافیک بالا یا فروشگاه‌های بزرگ‌تر، در آینده مهاجرت به یک هاست پولی توصیه می‌شود.
